# pigeonTest

Hero section for PigeonM, built from the Figma design (`PigeonM`, node `182:12148`).

Plain HTML / CSS / JS, no build step:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

- `index.html` — markup
- `css/hero.css` — styles (design width 1440 × 810)
- `js/hero.js` — intro animation and Business ↔ Residential switching
- `assets/` — images and icons exported from Figma
